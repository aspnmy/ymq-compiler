
**YMQ-Compiler（v2.0）** 是一个**面向大语言模型的架构感知型后训练量化编译器**，运行在 `llama.cpp` / GGUF 框架之上。

---

## 项目核心定位

它解决的是：标准量化流程把 Transformer 权重当作均匀数据处理，用粗暴的低比特压缩去挤压模型内部精细的路由机制，导致**高上下文格式循环、文本退化、"终点失忆"（finish-line amnesia）** 等问题。YMQ-Compiler 通过动态解析模型矩阵、采用多层级数据科学评估矩阵来避免这些问题。

---

## 四大核心技术

| 技术 | 说明 |
|------|------|
| **对数空间差距检测聚类** | 不在原始线性权重上操作（70k+ 的巨大数据会淹没中间推理信号），而是在对数空间中计算统计聚类方差，动态隔离中间逻辑尖峰（得分 72~512），将其提升到高精度非线性 4-bit（IQ4_XS），同时将闲置背景层压缩到 2-bit（IQ2_S）以最大化比特效率 |
| **衰减边界渐缩** | 对输入端脆弱的 token 向量做渐进式缓冲（L00=IQ4_NL → L01=IQ4_XS → L02=IQ3_XXS），最终出口层锁定 IQ4_NL 保证与词表头的无损握手 |
| **专用并行门控隔离** | 自动检测 Attention 和 Mamba SSM 路由网络的敏感层，将其保持在未量化原始精度（Q8_0/COPY），防止深层提示中的累积上下文漂移 |
| **非对称词表保护** | 将 tied-weight 嵌入数组（token_embd.weight 和 output.weight）锁定到高精度矩阵，确保在 43kb+ 上下文下也能正确解析闭合括号、系统命令键等特殊 stop-token |

---

## 五种量化预设（按 VRAM 预算）

- **XXS**：极致压缩，核心块使用 IQ2_XXS，适合单 GPU 资源紧张场景
- **XS**：平衡型，主峰 IQ4_NL + 中间 IQ3_S
- **M**：**推荐甜点**，背景层 IQ3_XXS + 主逻辑 IQ5_K，完全免疫高上下文失忆
- **L**：高端单 GPU，6-bit 重盾 + 4-bit 非线性背景
- **XL**：最高保真度，完整矩阵保护，适合大规模代码库解析

## 使用方式

1. 安装 `gguf` Python 库 + `llama-quantize` 二进制
2. 准备 `model.imatrix.gguf`（重要性矩阵）和 `model.gguf`（16 位源模型）
3. 运行：`./ymq-compile.sh <imatrix文件> <模型文件> --preset m`
4. 脚本自动生成 `run_quant.sh`，执行即可产出量化后的 GGUF 文件
